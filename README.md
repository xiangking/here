# here

here 是一个常驻桌面的 AI 伴侣精灵。当前版本已经收紧为精灵运行所需的核心链路：Agent 后端负责智能推理，here 负责角色人设、长期记忆、立绘、情绪、语音、输入和聊天演出。

## 保留内容

| 模块 | 说明 |
|------|------|
| Agent 后端 | 在主窗口菜单中选择 Hermes Agent、Internal Agent 或自动兜底。 |
| 人物设定 | 导入 / 编辑角色、立绘、情绪标签、角色语音引用与角色包。 |
| 背景管理 | 导入 / 编辑背景图组、BGM 与背景描述。 |
| 聊天模板 | 选择出场角色和背景，生成模板，保存并启动聊天。 |
| 聊天主窗 | 对话、立绘切换、TTS 播放、麦克风输入、历史保存与恢复。 |
| 主动联系 | 角色可按自己的日程状态主动联系用户，并可选择通过桌面、微信等外部渠道送达。 |
| 主动附图 | 主动联系可附带当前状态照片；生图接口可在菜单中切换 image-api、Grok Imagine、GPT Image 等适配器。 |

## 已移除内容

非必要入口已经移出主流程。生图统一走通用生图 API，后续可按需要接入外部服务。

## 快速开始

1. 启动主程序：源码运行 `python main.py`，整合包使用包内启动脚本。
2. 在主窗口菜单的「API / Agent 后端」中选择 Hermes Agent、Internal Agent 或自动兜底。
3. 在主窗口菜单中创建或导入角色。
4. 与桌面精灵对话。

## 可选配置

TTS 可使用在线服务或自行准备本地服务；不需要语音合成时选择“不使用”。ASR 默认保留 Vosk，也可按需下载 Whisper / RealtimeSTT 模型。生图 API 可留空，需要实时 CG、立绘生成或主动联系附图时再填写。

主动联系位于主窗口设置菜单。外部送达渠道在「聊天平台 / 外部发送」中配置；主动联系附图在「主动联系 / 附图设置」中配置，可单独填写 API URL、API Key、模型和尺寸等生图参数。默认配置不包含任何真实密钥，本地运行时配置保存在 `.local/` 或系统应用目录中。
